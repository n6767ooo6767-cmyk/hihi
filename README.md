# OnePlace

Игровая платформа для билетов, сообщений и игровых посылок. Адаптирована для телефона и компьютера.

## Подключение
1. Открой Supabase SQL Editor и выполни `supabase-setup.sql` (если первая схема уже была выполнена, используй `supabase-v2-functions.sql`).
2. В Supabase Authentication включи Email provider.
3. Для регистрации без подтверждения почты можно отключить Confirm email в настройках Auth (для игрового тестового проекта).
4. Открой сайт через GitHub Pages или локальный веб-сервер.

Публичные настройки проекта находятся в `js/config.js`. Publishable key предназначен для браузера; никогда не добавляй secret/service_role key в этот файл.

## Роли
Новые аккаунты всегда создаются как player с балансом 1000. Роль admin или guard нельзя выбрать при регистрации. Назначай роли вручную в Supabase SQL Editor только доверенным тестовым аккаунтам:

```sql
-- Подставь UUID нужного пользователя из Authentication → Users.
update public.profiles set role = 'admin', balance = 32 where id = 'USER_UUID';
update public.profiles set role = 'guard' where id = 'GUARD_USER_UUID';
```

## Возможности
- Регистрация и вход через Supabase Auth.
- Баланс и счётчики из базы данных.
- Создание билетов администратором с QR-кодом.
- Отправка сообщений администратором с подтверждением.
- Регистрация игровых посылок и обновление статусов персоналом.
- Проверка билета охранником.
- Звуки и разрешение браузерных уведомлений.

## Важно
Это игровая система: деньги условные, доставка виртуальная. Перед публичным запуском проверь RLS и правила доступа в Supabase. Для QR-сканирования камерой понадобится отдельная библиотека и HTTPS; пока доступна проверка кода вручную.
