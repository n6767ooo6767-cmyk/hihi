# OnePlace — игровая демоверсия

Открой `index.html` в браузере. Нажми «Включить звук», затем «Открыть кабинет».

## Уже есть
- адаптивный дизайн для телефона и компьютера;
- звуки интерфейса после нажатия кнопки;
- запрос разрешения на браузерные уведомления;
- переключение режима игрока и администратора;
- создание игровых билетов с QR-кодами;
- отправка тестовых сообщений с подтверждением;
- сохранение данных в браузере.

## Важно
Это локальная демоверсия: сообщения не пересылаются на другие устройства. Для настоящих аккаунтов и сообщений понадобится сервер. QR-код загружается из CDN, поэтому для его создания нужен интернет.
